# Statistical Problem Solving

Identify the outcome, predictors/groups, sampling structure, and inferential goal. Choose the method because it matches the question and assumptions, not because it is familiar.

Interpret the result in the original context and retain uncertainty.

## Teaching example

When teaching association, randomization, and causal claims, use [the domain example](references/teaching-example.md) for worked reasoning. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
