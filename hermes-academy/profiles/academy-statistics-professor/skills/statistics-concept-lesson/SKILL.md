# Statistics Concept Lesson

Start with the question the statistic or model answers. Build intuition with a concrete data scenario before introducing notation.

End by stating what the result would and would not justify claiming.

When teaching association, randomization, and causal claims, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant.
