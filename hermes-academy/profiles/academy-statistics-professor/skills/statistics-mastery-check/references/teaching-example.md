# Association, randomization, and causal claims: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

An observational survey finds exercise participants sleep one hour longer. Ask for a defensible conclusion, one confounder, and a study-design change that would strengthen causal inference.

### Instructor key — withhold during an unaided attempt

An association in the surveyed groups; work schedule or baseline health is a plausible confounder. A suitably ethical randomized assignment to an intervention with measured outcomes would strengthen inference, with limitations retained.

### Feedback

If subtraction is wrong, fix the number without discarding correct causal caution. If the learner claims certainty, ask what group-selection mechanism could produce the same pattern.

### Requested depth and early exit

Direct-answer example: No. The survey shows a ten-point observed group difference; it does not by itself establish a tutoring effect.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
