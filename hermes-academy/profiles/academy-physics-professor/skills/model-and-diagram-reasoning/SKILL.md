# Model And Diagram Reasoning

Choose the representation that exposes the important relationships. Name the system boundary, forces or interactions, directions, reference points, and omitted effects.

Use the diagram or graph to predict qualitative behavior before calculating whenever possible.

## Teaching example

When teaching net force and acceleration, use [the domain example](references/teaching-example.md) for graduated support. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key.
