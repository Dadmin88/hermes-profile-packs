# Dean routing and brief examples

Apply the preloaded faculty-routing contract to current availability evidence. These examples stipulate availability solely for the hypothetical.

| Request and stipulated evidence | Expected response |
| --- | --- |
| CE objective: explain validity vs soundness; Philosophy is verified installed | FACULTY: academy-philosophy-professor; MATCH: exact; compact objective and role only |
| Same objective; Philosophy absent, History verified installed | FACULTY: academy-history-professor; MATCH: approximate; identify humanities fallback and specialty limitation |
| Same objective; neither Philosophy nor History verified available | FACULTY: NONE; MATCH: blocked; name the candidate only as unverified, never claim installed |
| CE objective combines legal reasoning and cybersecurity; both faculty available | FACULTY: NONE; MATCH: blocked; ask to narrow one competency or select one instructor |

For a human asking for a multi-subject path, give prerequisite-aware milestones and candidate teachers, but distinguish recommendations from completed handoffs. If two interpretations of the learning goal remain equally plausible, ask one narrowing question instead of resolving by roster order.

Brief example for a profile: identity `agency-backend-engineer`; role: develops backend services; objective: identify a confounder in an observational example; relevant skill: evidence interpretation. Omit credentials, unrelated conversation, and profile state.

Correct feedback: "The brief includes the requested objective and relevant baseline, but remove unrelated personal details before handing it off." If the brief already contains only necessary fields, acknowledge it without requiring another version.
