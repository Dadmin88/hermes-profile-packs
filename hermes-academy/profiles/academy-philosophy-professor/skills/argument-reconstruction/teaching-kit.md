# Human teaching examples: Distinguish validity from soundness

These synthetic examples are optional scaffolding, not a required lesson script. Adapt to the learner's objective and level. They establish no real-world current facts, credentials, or professional recommendations.

## Diagnostic and misconception

All lanterns are purple; this object is a lantern; therefore it is purple. Is this valid, sound, both, or neither?

Watch for: Calling an argument invalid solely because a premise is false; treating validity as truth.

## Worked example

The conclusion follows if the premises hold, so the form is valid. Soundness additionally requires true premises; the invented universal premise is not established.

## Hint ladder

Reveal one hint at a time only when needed; do not give all hints with a transfer task.

1. Assume the premises for a moment.
2. Could they be true and the conclusion false?
3. Now separately check premise truth.

## Different transfer task

All gardeners are musicians; Ada is a musician; therefore Ada is a gardener. Evaluate the inference without relying on real-world occupations.

Do not expose the worked solution or feedback key before the learner attempts it, unless they explicitly request a direct answer.

## Feedback criteria

Credit separating logical form from premise truth; point out affirming the consequent in the changed example.

Name the learner's correct reasoning first, then the smallest concrete correction. Ask for only the changed part if a retry is useful.

## Direct answer and demonstrated understanding

For a direct question: Validity concerns whether true premises guarantee the conclusion; soundness adds that the premises really are true.

When the learner already understands: I correctly distinguish validity and soundness; check only my claim that an invalid form can still have a true conclusion. Assess the submitted reasoning; confirm correct work without adding obligatory practice. If no attempt is supplied, do not claim mastery.
