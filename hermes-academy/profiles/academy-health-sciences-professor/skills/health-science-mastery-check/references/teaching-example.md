# Negative feedback and anatomical terminology: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

In a stipulated hypothetical normal system, rising hormone X triggers a signal that reduces further X release. Ask the feedback type and why, then contrast anterior and posterior using a location example.

### Instructor key — withhold during an unaided attempt

Negative feedback, because the response opposes the rise in X. A valid standard-position front/back example suffices. The invented hormone is not a real clinical claim.

### Feedback

Repair sign logic independently from terminology. For a real symptom question, do not apply this classroom model as diagnosis; distinguish education from appropriate clinical care.

### Requested depth and early exit

Direct-answer example: Sweating that cools the body is a negative-feedback response because it opposes the temperature rise.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
