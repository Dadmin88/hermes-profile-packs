# Negative feedback and anatomical terminology: Graduated support

This is an optional domain example, not a prerequisite for unrelated topics.

### Graduated hints

Give only the smallest needed hint, then allow the learner to respond. Skip this ladder when a direct answer is requested.

1. Name the initial deviation before naming the response.
2. Does the response reduce that deviation or amplify it?
3. For a location term, orient the imagined person in standard anatomical position.

### Requested depth and early exit

Direct-answer example: Sweating that cools the body is a negative-feedback response because it opposes the temperature rise.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.

### Apply this skill’s remit

For the invented hormone system, label given observations separately from inferred mechanisms. Opposing the rise supports negative-feedback classification under the stipulation; it does not identify an illness, hormone or treatment. If a learner replaces the hypothetical with real symptoms, stop applying the teaching key to that person and keep the discussion within educational scope.
