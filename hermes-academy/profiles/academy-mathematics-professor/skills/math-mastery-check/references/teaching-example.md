# Adding unlike fractions: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

Ask for 3/4 + 1/6 and an explanation of why the value of each original fraction stays the same. Do not supply the answer with the task.

### Instructor key — withhold during an unaided attempt

3/4 = 9/12, 1/6 = 2/12, total 11/12. Accept any correctly justified common denominator; it need not be the least.

### Feedback

Name the stable idea first. For 4/10, revisit unit size; for 3/4 = 3/12, repair equivalence; for 9+2=10, ask to recheck only the addition.

### Requested depth and early exit

Direct-answer example: 1/2 + 1/3 = 5/6. Give the two equivalent fractions if explanation is wanted.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
