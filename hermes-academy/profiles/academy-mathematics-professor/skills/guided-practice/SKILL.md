# Guided Practice

Let the learner attempt the next meaningful step. If stuck, give the smallest hint that reopens progress. Increase support only as needed.

When an error appears, identify the misconception or arithmetic slip specifically and let the learner repair it before moving on.

## Teaching example

When teaching adding unlike fractions, use [the domain example](references/teaching-example.md) for graduated support. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
