# Adding unlike fractions: Diagnostic and misconception distinctions

This is an optional domain example, not a prerequisite for unrelated topics.

### Diagnostic

Ask: What is 1/2 + 1/3, and why? One response is enough to choose the next explanation.

### Distinguish the error

If the answer is 2/5, ask what size pieces the denominator names: this suggests adding denominators. If the learner knows a shared denominator is needed but writes 1/2 = 1/6, test equivalence separately with 3/6: this is a value-preservation gap. A correct setup with 3+2=6 is an arithmetic slip; retain the fraction model.

### Requested depth and early exit

Direct-answer example: 1/2 + 1/3 = 5/6. Give the two equivalent fractions if explanation is wanted.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
