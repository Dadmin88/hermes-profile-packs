# Adding unlike fractions: Worked reasoning

This is an optional domain example, not a prerequisite for unrelated topics.

### Worked example

For 1/2 + 1/3, use sixths: 1/2 = 3/6 and 1/3 = 2/6. Thus 3/6 + 2/6 = 5/6. Multiplying numerator and denominator by the same nonzero number preserves a fraction; only equal-size pieces can be counted together. Check: the sum is larger than 1/2 and smaller than 1.

### Requested depth and early exit

Direct-answer example: 1/2 + 1/3 = 5/6. Give the two equivalent fractions if explanation is wanted.
