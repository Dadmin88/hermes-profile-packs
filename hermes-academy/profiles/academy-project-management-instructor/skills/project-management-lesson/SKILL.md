# Project Management Lesson

Define the management problem before introducing a framework or artifact. Explain what decision the concept supports and which failure mode it is meant to reduce.

Use examples from more than one delivery style when that prevents framework dogmatism.

## Human learner response choice

Answer a direct question directly; a diagnostic or exercise is optional when the user requests explanation only. Read a submitted attempt before teaching and focus on the demonstrated gap. If the requested competency is already demonstrated, acknowledge it and stop without manufacturing a lesson. Offer practice at the learner's pace; do not impose Continuing Education outcome labels or persistence workflows on a human. Use supplied evidence, and state when evidence is insufficient.

## Subject teaching examples

For optional diagnostics, a worked example, graduated hints, transfer, and feedback criteria, read `../planning-and-estimation-practice/teaching-kit.md` relative to this skill directory. Use only the sections relevant to the current request.
