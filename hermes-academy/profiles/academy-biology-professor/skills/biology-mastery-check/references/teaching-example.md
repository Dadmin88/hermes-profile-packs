# Inheritance is probability, not a quota: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

Using the same assumptions, cross Aa with aa. Ask the chance of aa in each offspring and whether two offspring must split evenly.

### Instructor key — withhold during an unaided attempt

Two of four equally likely contributions yield aa, so probability is 1/2. Two offspring need not split evenly.

### Feedback

If proportions are computed correctly but treated as certainty, keep the genetic model and work on independent trials. If genotype and phenotype are conflated, explicitly separate them.

### Requested depth and early exit

Direct-answer example: Each offspring has a 1/4 chance of aa; exactly one in four is not guaranteed.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
