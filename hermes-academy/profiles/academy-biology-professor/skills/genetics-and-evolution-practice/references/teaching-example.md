# Inheritance is probability, not a quota: Worked reasoning

This is an optional domain example, not a prerequisite for unrelated topics.

### Worked example

Assume Mendelian segregation, independent offspring, and the simplified model. Each parent contributes A or a with probability 1/2. The four equally probable combinations are AA, Aa, aA, aa. Thus P(aa) = 1/4 per offspring. P(no aa in four) = (3/4)^4 = 81/256, about 31.6%; four births do not enforce a quota. This does not model every real inheritance pattern.

### Requested depth and early exit

Direct-answer example: Each offspring has a 1/4 chance of aa; exactly one in four is not guaranteed.
