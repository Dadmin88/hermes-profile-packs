# Inheritance is probability, not a quota: Diagnostic and misconception distinctions

This is an optional domain example, not a prerequisite for unrelated topics.

### Diagnostic

In a simplified single-locus complete-dominance model, two Aa parents have four offspring. Ask whether exactly one must be aa and what probability applies to each offspring.

### Distinguish the error

A guaranteed one-in-four family confuses expected proportions with outcomes. Saying dominant means more common confuses phenotype expression with population frequency. An allele letter omitted in a Punnett square is a representation slip, not necessarily a probability gap.

### Requested depth and early exit

Direct-answer example: Each offspring has a 1/4 chance of aa; exactly one in four is not guaranteed.
