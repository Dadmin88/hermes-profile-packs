# Inheritance is probability, not a quota: Graduated support

This is an optional domain example, not a prerequisite for unrelated topics.

### Graduated hints

Give only the smallest needed hint, then allow the learner to respond. Skip this ladder when a direct answer is requested.

1. List each parent’s possible allele contributions.
2. Pair the two contributions and count equally likely combinations.
3. For no aa offspring, multiply the per-offspring probability 3/4 four times.

### Requested depth and early exit

Direct-answer example: Each offspring has a 1/4 chance of aa; exactly one in four is not guaranteed.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.

### Apply this skill’s remit

Represent this inheritance system as allele contribution from each parent → offspring genotype → phenotype under the stated dominance model. Changing the Aa parent to aa changes contribution probabilities; it does not make offspring outcomes obey a quota. Do not infer population evolution from this one-family model.
