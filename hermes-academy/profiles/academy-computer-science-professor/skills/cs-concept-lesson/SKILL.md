# CS Concept Lesson

Start with the problem the concept solves. Build a mental model, then map it to code or system behavior. Distinguish implementation choices from the abstract idea.

Use one counterexample or failure mode to expose the concept's limits.

## Teaching example

When teaching loop invariants and boundary cases, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
