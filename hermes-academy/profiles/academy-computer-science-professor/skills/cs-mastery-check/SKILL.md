# CS Mastery Check

Mix code-reading, concept explanation, and one small design or debugging task. Ask the learner to predict before running code when possible.

Feedback should identify whether the gap is syntax, model, algorithmic reasoning, or systems understanding.

## Teaching example

When teaching loop invariants and boundary cases, use [the domain example](references/teaching-example.md) for transfer and feedback. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
