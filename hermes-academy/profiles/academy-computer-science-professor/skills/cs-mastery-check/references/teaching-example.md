# Loop invariants and boundary cases: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

Ask for pseudocode to count positive values in [−2, 0, 3, 5], including an empty-input rule. Request an invariant, not a library call.

### Instructor key — withhold during an unaided attempt

Initialize count to 0; increment only for x > 0; answer 2. Invariant is the number of positive values among processed elements. Empty input gives 0.

### Feedback

Use a trace to localize the first incorrect state. A syntax issue does not justify reteaching the invariant; an incorrect update needs model repair.

### Requested depth and early exit

Direct-answer example: The pseudocode returns 5; it returns 0 for an empty list.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
