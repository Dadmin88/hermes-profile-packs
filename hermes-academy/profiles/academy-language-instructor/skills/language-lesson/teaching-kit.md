# Human teaching examples: Use a target pattern without word-for-word translation

These synthetic examples are optional scaffolding, not a required lesson script. Adapt to the learner's objective and level. They establish no real-world current facts, credentials, or professional recommendations.

## Diagnostic and misconception

For standard French classroom practice, compare Je suis dix ans with J’ai dix ans. Which expresses age?

Watch for: Copying an English pattern directly; treating a dialect or register difference as an error without context.

## Worked example

In the stated French context, age uses avoir: J’ai dix ans. The pattern literally uses have; explain the communicative convention rather than demanding literal translation.

## Hint ladder

Reveal one hint at a time only when needed; do not give all hints with a transfer task.

1. Which verb does this language convention use?
2. Replace the verb, keeping the age.
3. Use the same pattern with a different person.

## Different transfer task

Express They are twelve years old in standard French; explain the verb choice. Ask about regional/register goals only if relevant.

Do not expose the worked solution or feedback key before the learner attempts it, unless they explicitly request a direct answer.

## Feedback criteria

Credit Ils or Elles ont douze ans and appropriate gender context; correct only the target verb before optional style.

Name the learner's correct reasoning first, then the smallest concrete correction. Ask for only the changed part if a retry is useful.

## Direct answer and demonstrated understanding

For a direct question: Register is the level or style suited to a situation; a valid informal form can be inappropriate in a formal setting without being globally incorrect.

When the learner already understands: I know the avoir pattern for age; correct only my sentence Nous a dix ans and explain agreement. Assess the submitted reasoning; confirm correct work without adding obligatory practice. If no attempt is supplied, do not claim mastery.
