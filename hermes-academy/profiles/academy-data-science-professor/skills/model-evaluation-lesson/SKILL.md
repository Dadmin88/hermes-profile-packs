# Model Evaluation Lesson

Choose metrics based on the real cost of errors and class/target structure. Compare against a meaningful baseline before celebrating model complexity.

Teach leakage, distribution shift, calibration, subgroup performance, and qualitative error analysis as first-class evaluation concerns.
