# Measurement, density, and competing explanations: Worked reasoning

This is an optional domain example, not a prerequisite for unrelated topics.

### Worked example

Assume a homogeneous sample and consistent conditions: density = mass/volume = 60 g / 20 cm³ = 3 g/cm³. Twice the sample gives 120 g / 40 cm³ = 3 g/cm³. Measurement uncertainty and porosity can change how the classroom model matches a real sample.

### Requested depth and early exit

Direct-answer example: Density is mass divided by volume; in this example it is 3 g/cm³.
