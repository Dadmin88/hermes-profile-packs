# Molecular Structure Reasoning

Move from valence/electron considerations to bond type, geometry, polarity, intermolecular interactions, and predicted properties.

Treat structural drawings as models. Explain which features are being represented and which are omitted.

## Teaching example

When teaching particle structure and stoichiometric ratios, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
