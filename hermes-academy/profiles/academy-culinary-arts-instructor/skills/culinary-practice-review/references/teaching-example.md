# Scaling a recipe without overclaiming equivalence: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

A written dressing formula uses 90 mL oil and 30 mL vinegar. Ask for a two-thirds batch, the ratio, and why scaling alone gives no storage-safety guarantee.

### Instructor key — withhold during an unaided attempt

60 mL oil and 20 mL vinegar, still 3:1. Ingredient proportions alone do not establish validated safe storage conditions.

### Feedback

If the arithmetic is right, move to ingredient function or process. If separation occurs, explain dispersion rather than blaming incorrect scaling without evidence. Never infer safety from aroma alone.

### Requested depth and early exit

Direct-answer example: A half batch uses 30 mL oil and 10 mL vinegar. Process time does not necessarily halve.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.
