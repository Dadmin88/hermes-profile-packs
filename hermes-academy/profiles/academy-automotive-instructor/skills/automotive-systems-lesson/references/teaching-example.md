# Fault codes are evidence, not parts orders: Diagnostic and misconception distinctions

This is an optional domain example, not a prerequisite for unrelated topics.

### Diagnostic

In a paper-only fictional vehicle case, a controller reports a sensor-circuit fault. Ask whether this alone proves the sensor needs replacement and what other categories could explain it.

### Distinguish the error

A circuit fault can involve wiring, connector, supply, ground, sensor, or controller; its label does not prove a component. A single observation is not a confirmed root cause. A mistaken label after a correct causal chain is a terminology slip.

### Requested depth and early exit

Direct-answer example: No. A sensor-circuit code does not by itself prove the sensor is faulty.
