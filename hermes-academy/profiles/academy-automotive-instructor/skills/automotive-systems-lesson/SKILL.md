# Automotive Systems Lesson

Map the system from input to output and identify mechanical, electrical, fluid, or network interactions. Explain what normal operation looks like before discussing failures.

Use vehicle-specific data only when verified.

## Teaching example

When teaching fault codes are evidence, not parts orders, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key.
