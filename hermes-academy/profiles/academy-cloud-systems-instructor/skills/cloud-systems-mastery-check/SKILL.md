# Cloud Systems Mastery Check

Present a compact architecture and ask the learner to trace normal operation, identify stateful components, predict two failure effects, and propose an observable recovery strategy.

Reward causal systems reasoning over vendor terminology.

## Teaching example

When teaching retries, durable state, and duplicate effects, use [the domain example](references/teaching-example.md) for transfer and feedback. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key.
