# Cloud Concept Lesson

Start from the computing problem being solved. Map processes, data, network boundaries, and ownership of state, then introduce the abstraction or service.

Separate durable fundamentals from provider-specific implementation details.

## Teaching example

When teaching retries, durable state, and duplicate effects, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key.
