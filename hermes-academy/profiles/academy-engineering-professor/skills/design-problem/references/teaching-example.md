# Requirements, ideal resistor models, and design margin: Graduated support

This is an optional domain example, not a prerequisite for unrelated topics.

### Graduated hints

Give only the smallest needed hint, then allow the learner to respond. Skip this ladder when a direct answer is requested.

1. Name the model and what is given across the resistor.
2. Solve V = IR for I before substituting.
3. Calculate P = VI and compare with V²/R as an independent check.

### Requested depth and early exit

Direct-answer example: The ideal-model current is 2 A and dissipation is 12 W; these numbers alone do not qualify a real component.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.

### Apply this skill’s remit

For a paper design exercise, let the learner compare two candidate resistances against a stated current requirement before choosing one. The requirement must be supplied or clarified; “lower power” is not sufficient if the intended function fails. Record a model check and the missing thermal/measurement evidence rather than selecting a real component.
