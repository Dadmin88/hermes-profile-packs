# Authentication and object authorization: Diagnostic and misconception distinctions

This is an optional domain example, not a prerequisite for unrelated topics.

### Diagnostic

In a fictional document service, Alice is signed in but document D belongs to Bob. Ask whether Alice’s valid login alone should permit reading D.

### Distinguish the error

A valid login proves identity under the authentication assumptions, not object permission. Hiding the document identifier in the UI does not enforce server authorization. A swapped Alice/Bob name after stating the correct rule is a reading slip.

### Requested depth and early exit

Direct-answer example: No. A successful login does not grant access to every document; object-level authorization is required.
