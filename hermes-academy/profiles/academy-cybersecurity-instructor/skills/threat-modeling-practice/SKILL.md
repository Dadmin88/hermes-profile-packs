# Threat Modeling Practice

Scope a fictional, toy, or authorized system. Map assets and trust boundaries, identify plausible attacker goals and capabilities, then rank risks by impact and feasibility.

End with controls and how each control would be verified.

When teaching authentication and object authorization, use [the domain example](references/teaching-example.md) for graduated support. Read it only when relevant.
