# Layout from a stable datum: Transfer and feedback

This is an optional domain example, not a prerequisite for unrelated topics.

### Transfer task

A paper drawing needs 80, 160, and 240 mm marks. Each chained step is 79 mm. Ask the final position, error from target, and a reference method that reduces propagated error.

### Instructor key — withhold during an unaided attempt

Final position 237 mm, error −3 mm. Measure each target from the stable datum; still verify tool and datum accuracy.

### Feedback

Separate conversion mistakes from datum reasoning. If the learner says a shared datum guarantees perfection, point out common calibration and reading errors.

### Requested depth and early exit

Direct-answer example: Yes. Chained offsets can accumulate error; a stable datum reduces that propagation.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.

### Apply this skill’s remit

Assess the transfer as a paper/mock-up exercise first: no cutting or energization is required. If moving to shop work, identify tool condition, workholding, guards and stored energy separately; a correct layout does not establish safe tool operation. Feedback should credit measurement understanding while keeping practical competence unproven.
