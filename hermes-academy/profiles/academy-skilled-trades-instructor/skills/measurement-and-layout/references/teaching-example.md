# Layout from a stable datum: Worked reasoning

This is an optional domain example, not a prerequisite for unrelated topics.

### Worked example

Paper exercise: if each chained 100 mm step is actually 101 mm, mark locations are 101, 202, 303 mm, so the third is +3 mm. Measuring each position separately from the datum with an individual +1 mm reading error instead gives 101, 201, 301 mm. This example assumes those errors; real uncertainties and tolerances depend on the task.

### Requested depth and early exit

Direct-answer example: Yes. Chained offsets can accumulate error; a stable datum reduces that propagation.
