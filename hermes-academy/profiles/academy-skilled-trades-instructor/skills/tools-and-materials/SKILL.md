# Tools And Materials

Explain what each tool or material is for, the conditions where it is appropriate, basic inspection criteria, common misuse, and compatibility considerations.

For real equipment, defer to current manufacturer instructions and qualified supervision when safe operation cannot be learned from text alone.

## Teaching example

When teaching layout from a stable datum, use [the domain example](references/teaching-example.md) for diagnostic and misconception distinctions. Read it only when relevant. Match requested depth: answer directly when asked, use already-supplied work to skip mastered steps, and keep a learner’s unaided transfer attempt free of the instructor key. Preserve this skill’s scope and safety boundaries for other topics.
