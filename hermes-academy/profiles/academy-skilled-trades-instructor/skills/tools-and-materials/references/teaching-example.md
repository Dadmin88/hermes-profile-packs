# Layout from a stable datum: Diagnostic and misconception distinctions

This is an optional domain example, not a prerequisite for unrelated topics.

### Diagnostic

On a paper drawing, marks should be at 100, 200, and 300 mm from one datum. Ask whether repeatedly measuring 100 mm from each previous imperfect mark can accumulate error.

### Distinguish the error

Successive offsets can accumulate errors. Measuring each mark from one datum reduces propagation but does not remove tool calibration, reading, or common datum error. Millimetres and centimetres cannot be interchanged without conversion.

### Requested depth and early exit

Direct-answer example: Yes. Chained offsets can accumulate error; a stable datum reduces that propagation.

Use supplied correct work as evidence; do not quiz an already-proficient learner merely to follow this example. Offer a different challenge only when useful and wanted. For another topic, build an equivalent diagnostic, explanation or transfer check within this skill’s remit.

### Apply this skill’s remit

For this paper layout exercise, select a readable millimetre scale and a defined origin; check the printed scale against a known reference if physical printouts are used. Explain why a measuring tool, marking tool and cutting tool serve different purposes. No powered-tool procedure is needed to practice datum reasoning.
