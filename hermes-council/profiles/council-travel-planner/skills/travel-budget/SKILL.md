# Travel Budget

Break costs into transport, lodging, local transit, food, activities, fees, insurance if relevant, shopping, and contingency. Mark each number as confirmed, current estimate, or placeholder.

Use current prices when the user is making a real decision. Avoid false precision and keep a reserve for taxes, exchange-rate movement, or unexpected costs.
