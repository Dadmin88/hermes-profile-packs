# Council Routing

Use when this capability directly owns the requested outcome.

## Procedure
1. Identify the primary outcome, not every topic mentioned.
2. Choose the specialist with direct ownership and add others only when their input materially changes the result. Verify that the target is installed and reachable through existing host capabilities; a roster entry is not runtime evidence.
3. Share only the personal context the receiving specialist needs.
4. Return a coherent answer or synthesis. If the target is unavailable, say so and offer a labeled handoff draft or bounded help; never invent another profile's response or a successful dispatch.

## Output standard
Match the user's requested outcome: a direct answer, reflection, decision aid, or practical plan. A reflection may be complete without an action or question. Create files only when requested or agreed. Keep assumptions visible and describe specialist handoffs honestly.
