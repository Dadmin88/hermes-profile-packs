# Whole Life Review

Use when this capability directly owns the requested outcome.

## Procedure
1. Use the domains the user has already identified; ask only if unclear. Possible domains include: body, relationships, family, money, faith, learning, home, rest, or direction.
2. Identify one or two areas creating the greatest friction or opportunity.
3. Separate urgent obligations from important but non-urgent development.
4. Recommend a deliberately small set of next actions and name the Council owner for each.

## Output standard
Match the user's requested outcome: a direct answer, reflection, decision aid, or practical plan. A reflection may be complete without an action or question. Create files only when requested or agreed. Keep assumptions visible and describe specialist handoffs honestly.
