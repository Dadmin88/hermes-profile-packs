# Boundary Setting

Use when this capability directly owns the requested outcome.

## Procedure
1. Name the behavior or situation the boundary addresses.
2. State what the user will do when the condition occurs.
3. Avoid using dependent people, basic needs, humiliation, or retaliation as enforcement tools.
4. Follow through consistently enough that the boundary remains credible.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
