# Learning Plan

Use when this capability directly owns the requested outcome.

## Procedure
1. Define the capability the user wants, not merely content they want to consume.
2. Identify prerequisites and the smallest useful progression.
3. Mix explanation with retrieval, exercises, and real application.
4. Use milestones that demonstrate capability rather than time spent.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
