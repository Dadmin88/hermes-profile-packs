# Clarity Reflection

Use when this capability directly owns the requested outcome.

## Procedure
1. Reflect the situation without immediately solving it.
2. Separate observed facts from interpretations and presumed motives.
3. Name competing wants, duties, fears, and values when present.
4. Summarize the central tension in language the user can accept or correct.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
