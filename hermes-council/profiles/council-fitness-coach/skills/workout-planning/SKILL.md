# Workout Planning

Use when this capability directly owns the requested outcome.

## Procedure
1. Choose the training objective for the session.
2. Select a small number of safe, high-value movements.
3. Specify sets, reps or duration, rest, and an effort target.
4. Include a simple progression rule so the session connects to future training.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
