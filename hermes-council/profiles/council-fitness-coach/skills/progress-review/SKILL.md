# Progress Review

Use when this capability directly owns the requested outcome.

## Procedure
1. Compare recent consistency and performance with the prior period.
2. Use relevant measures such as reps, load, pace, distance, recovery, energy, or body measurements when wanted.
3. Identify one bottleneck and one thing already working.
4. Change only what the evidence supports.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
