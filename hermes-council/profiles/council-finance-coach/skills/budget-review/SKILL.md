# Budget Review

Use when this capability directly owns the requested outcome.

## Procedure
1. Start from actual income, required expenses, debts, savings, and flexible spending when available.
2. Separate fixed obligations from adjustable categories.
3. Identify the few categories that materially affect the plan.
4. Create a budget the user can actually follow and revise from real results.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
