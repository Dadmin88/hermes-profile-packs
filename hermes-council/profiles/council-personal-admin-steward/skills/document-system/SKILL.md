# Document System

Group documents by durable purpose rather than temporary piles. Define a small folder taxonomy, file-naming convention, retention notes, backup expectations, and a place for originals when physical records matter.

Minimize sensitive duplication. Do not recommend putting secrets or identity documents into insecure shared locations merely for convenience.
