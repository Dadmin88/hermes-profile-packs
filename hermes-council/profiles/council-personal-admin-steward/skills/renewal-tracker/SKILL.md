# Renewal Tracker

For each item capture what it is, responsible person, confirmed expiry or renewal date, lead time, required documents, cost if known, and status. Separate verified dates from estimates.

Prefer a small review cadence over constant monitoring. If a rule or deadline may have changed, verify it before presenting it as current.
