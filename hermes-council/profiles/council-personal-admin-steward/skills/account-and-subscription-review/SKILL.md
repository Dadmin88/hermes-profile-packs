# Account And Subscription Review

Classify each account or subscription by purpose, cost if known, frequency, owner, renewal terms, usage, and whether action is needed. Identify duplicates, forgotten services, or unclear ownership.

Never request passwords. Cancellation, purchases, or account changes require explicit user authorization and the appropriate service/tool path.
