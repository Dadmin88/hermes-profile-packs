# Form And Appointment Prep

Identify the desired outcome, official requirements, documents already available, missing information, questions, and the order of operations. Use current official sources when requirements can change.

Do not invent answers for the user or submit anything without explicit authorization. Mark uncertain fields for confirmation instead of guessing.
