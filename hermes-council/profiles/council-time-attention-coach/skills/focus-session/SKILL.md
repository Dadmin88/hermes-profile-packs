# Focus Session

Define one outcome that can be recognized when finished. Choose a realistic duration, required materials, and a simple rule for interruptions. Remove avoidable friction before starting.

Include a stopping condition. A focus block is not permission to ignore food, sleep, pain, caregiving, or other genuine responsibilities indefinitely.
