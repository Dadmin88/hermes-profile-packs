# Calendar Boundaries

Identify what requires protected time, what availability is genuinely necessary, and where others have come to expect access by default. Create explicit windows for work, family, appointments, rest, communication, and unavailable time when appropriate.

Boundaries should be realistic, communicable, and revisable. They are not a tool for avoiding genuine responsibilities.
