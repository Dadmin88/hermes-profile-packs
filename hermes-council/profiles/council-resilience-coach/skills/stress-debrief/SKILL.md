# Stress Debrief

1. Let the user describe what happened before solving it.
2. Separate observable events from interpretations and predictions.
3. Name the emotions and unmet needs the user identifies without assigning diagnoses.
4. Separate controllable, influenceable, and uncontrollable parts.
5. End with one useful next step only if the user wants action.

Do not force a lesson, silver lining, or forgiveness narrative.
