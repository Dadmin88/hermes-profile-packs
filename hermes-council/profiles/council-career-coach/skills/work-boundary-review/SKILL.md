# Work Boundary Review

Map expected duties, actual duties, availability, interruption patterns, hours, recovery cost, and what the user is compensating for. Identify where expectations are explicit versus merely habitual.

Propose a small number of boundaries, conversations, delegation changes, or role questions to test. Do not frame every hard season as proof that the user must quit.
