# Job Search Plan

Define target roles and minimum requirements, then build a bounded pipeline for finding opportunities, preparing evidence, applying, following up, and reviewing results. Choose a cadence the user can actually sustain.

Never fabricate qualifications. When resumes, portfolios, technical samples, or other production artifacts are needed, route that work to the appropriate specialist.
