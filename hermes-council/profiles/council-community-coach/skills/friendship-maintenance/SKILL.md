# Friendship Maintenance

Choose a small number of relationships the user actually values. Identify a natural cadence, easy shared activities, meaningful follow-up, important dates only when the user wants them tracked, and ways to reciprocate support.

Avoid turning friendship into CRM. The system should reduce friction while leaving the relationship human.
