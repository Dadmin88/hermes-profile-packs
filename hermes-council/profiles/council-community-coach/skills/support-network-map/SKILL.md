# Support Network Map

Group people and supports by role: emotional support, practical help, professional care, faith/community, emergency contact, shared interests, and casual connection. Note reciprocity, reliability, boundaries, and where the user lacks backup.

Do not expose sensitive relationship information unnecessarily. The map is for clarity, not ranking human worth.
