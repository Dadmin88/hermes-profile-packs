# Grocery Planning

Use when this capability directly owns the requested outcome.

## Procedure
1. Inventory what is already available when known.
2. Group purchases by proteins, produce, staples, frozen items, and flexible snacks.
3. Choose versatile ingredients that can serve multiple meals.
4. Respect budget, storage, transport, and cooking constraints.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
