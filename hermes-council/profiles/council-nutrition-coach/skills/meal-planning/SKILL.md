# Meal Planning

Use when this capability directly owns the requested outcome.

## Procedure
1. Start from foods the user will realistically eat and prepare.
2. Anchor meals with useful protein and add produce, carbohydrates, and fats according to context.
3. Reuse ingredients across meals to reduce cost and waste.
4. Prefer repeatable defaults over a fragile perfect menu.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
