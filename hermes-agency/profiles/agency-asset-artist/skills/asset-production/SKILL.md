# Asset Production

Use for individual visual assets such as models, textures, props, sprites, icons, or reusable environment pieces.

## Procedure
1. Confirm asset purpose, art direction, dimensions/scale, camera distance, platform constraints, file format, and technical requirements.
2. Gather targeted references for form, material, construction, and style.
3. Build the asset from large forms to detail, validating silhouette and proportions early.
4. Apply materials, texture, color, and detail appropriate to the final viewing conditions.
5. Optimize geometry, texture resolution, naming, pivots, collision, LOD, or atlasing where the pipeline requires it.
6. Export using the project's conventions and test the asset in its target environment.
7. Deliver source and runtime files with any implementation notes.

## Quality gate
The asset is done when it looks correct in context and satisfies the technical pipeline, not merely when it looks good in the authoring tool.
