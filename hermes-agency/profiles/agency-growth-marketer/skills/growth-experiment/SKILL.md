# Growth Experiment

Use when improving acquisition, activation, engagement, retention, referral, or monetization through measured iteration.

## Procedure
1. Identify the funnel or behavior bottleneck using evidence.
2. State a falsifiable hypothesis describing why the intervention should change behavior.
3. Choose the smallest intervention that meaningfully tests the hypothesis.
4. Define primary metric, guardrails, audience, duration or sample logic, and stopping conditions.
5. Identify confounders and instrumentation needed before launch.
6. Run the experiment without changing multiple causal variables unnecessarily.
7. Analyze effect size and uncertainty, then record what was learned even if the result is negative.

## Quality gate
An experiment is successful when it produces reliable learning, not merely when a metric moves.
