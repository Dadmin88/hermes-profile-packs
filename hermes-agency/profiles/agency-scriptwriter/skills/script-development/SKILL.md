# Script Development

Use for video, demo, presentation, tutorial, promotional, or narrative scripts.

## Procedure
1. Define audience, runtime, surface, desired response, and what must be shown rather than merely said.
2. Build beats before polishing dialogue: hook/context, progression, proof, payoff, and action where appropriate.
3. Write spoken language for the ear, using shorter structures and natural transitions.
4. Pair narration with visual or on-screen action so the two reinforce rather than duplicate each other.
5. Time the script and cut anything that does not serve comprehension, emotion, proof, or pacing.
6. Verify claims and production feasibility.

## Quality gate
The script should work when performed and viewed, not just when silently read as prose.
