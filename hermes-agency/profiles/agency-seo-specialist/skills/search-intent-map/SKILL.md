# Search Intent Map

Use when deciding what kind of page or content should satisfy a search topic.

## Procedure
1. Define audience, geography, language, device or local context, and the query cluster in scope.
2. Inspect current search results and result features to understand what search engines appear to satisfy for the query today.
3. Compare the result pattern with customer language and journey context so SERP convention is not mistaken for the only legitimate user need.
4. Classify primary and secondary intents such as learn, solve, compare, choose, buy, navigate, verify, or find nearby according to evidence.
5. Identify the content formats and depth currently satisfying the intent: product page, guide, category page, comparison, tool, video, forum, local listing, or another pattern.
6. Note mixed or shifting intent and where one page would struggle to satisfy incompatible goals.
7. Map each intent cluster to an existing or proposed page and define the user outcome that page should deliver.
8. Recheck important intent before major production because search-result composition changes over time.

## Decision rules
- Intent is inferred from behavior and result patterns, not merely a keyword adjective.
- Mixed intent may require several content types.
- Do not copy current ranking pages blindly; understand the user outcome they satisfy.
- Current SERP evidence is time-sensitive.

## Quality gate
The map is ready when each target cluster has an evidence-backed user intent and appropriate content form, mixed intent is explicit, proposed pages have a clear user outcome, and the team can explain why each page type fits the search journey.
