# Deployment Readiness

Use the delivery path the user authorizes. For a routine change, check the affected build or startup path where relevant, smoke-check the changed workflow, and report what shipped. Keep canonical source and deployed changes aligned. Check configuration, migrations, permissions, compatibility, and recovery when the change materially affects them. Use staging, broader validation, or recovery rehearsals when the task calls for them.
