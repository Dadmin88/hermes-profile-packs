# Fullstack Testing

Start with a focused check of the changed user workflow. Reuse relevant passing evidence and existing tests. Add a focused regression when a bug could otherwise recur undetected. Check persistence, authorization, error handling, and compatibility where the change affects them. Run a broader suite when project requirements, user instructions, or the blast radius warrant it. Report checks actually run and any meaningful gap.
