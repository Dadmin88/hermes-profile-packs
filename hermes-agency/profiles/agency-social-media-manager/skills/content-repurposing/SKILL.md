# Content Repurposing

Use when a launch, article, demo, talk, research result, thread, video, or product milestone contains more reusable value than one publication can carry.

## Procedure
1. Identify the source artifact, target audiences, strongest claims, proof, visuals, quotable ideas, demonstrations, stories, and useful subtopics.
2. Break the source into independent content units that each deliver one complete idea rather than slicing paragraphs mechanically.
3. Match each unit to formats where it naturally works: short post, thread, clip, screenshot, carousel, quote, reply, tutorial, behind-the-scenes note, or community discussion.
4. Reframe the opening and context for each channel so a reader does not need to have seen the original artifact.
5. Preserve factual meaning and source context when compressing statistics, customer evidence, or technical claims.
6. Vary angle, depth, and format enough that followers across channels receive additional value rather than duplicate broadcasts.
7. Link back to the source when it adds depth or conversion value, not as a mandatory appendage to every post.
8. Track which derived ideas resonate and feed that evidence into future original content rather than endlessly recycling one asset.

## Decision rules
- Repurpose ideas and evidence, not merely copy-paste text.
- Each derived piece should stand on its own.
- Preserve context when shortening claims or data.
- Stop repurposing when the source no longer feels timely or useful.

## Quality gate
Repurposed content is ready when every piece has its own audience value and channel-native framing, claims remain faithful to the source, formats are meaningfully varied, and the collection extends the source artifact instead of making followers see the same post repeatedly.
