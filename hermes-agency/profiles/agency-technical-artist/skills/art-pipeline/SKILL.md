# Art Pipeline

Use when creative production is blocked by technical workflow, asset consistency, rendering, or runtime constraints.

## Procedure
1. Map the current path from source asset to runtime, including tools, formats, transforms, naming, metadata, and validation.
2. Reproduce the failure or inefficiency at the smallest useful scope.
3. Identify whether the cause is authoring, export, import, shader/material, coordinate/scale, tooling, or runtime behavior.
4. Define conventions and automated checks for repeatable failure classes.
5. Build helpers or technical solutions that preserve artist iteration speed.
6. Validate representative assets through the complete pipeline.
7. Document the workflow and known constraints for artists and engineers.

## Quality gate
The solution should reduce recurring friction without hiding important runtime or quality constraints from artists.
